# User Guide
## Customer
1. Browse the Marketplace to find equipment.
2. Select dates and create a booking.
3. Pay securely.
4. Pick up the equipment locally from the vendor.
5. Return and review.

## Vendor Admin
1. Register your business.
2. Once approved, add equipment.
3. Manage bookings and staff from the Dashboard.
4. Track revenue and reviews.

## Vendor Staff
1. Log in to process handovers.
2. Issue equipment to customers.
3. Receive equipment and report damages.

## Super Admin
1. Approve new vendors.
2. Manage global categories.
3. Monitor platform analytics.

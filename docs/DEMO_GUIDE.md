# College Demo Guide
## Sequence (10-15 minutes)
1. **Introduction**: Explain RentKart connects customers and local rental shops.
2. **Customer Flow**: Log in as customer, search "Camera", book for 2 days, complete checkout.
3. **Vendor Flow**: Log in as vendor, view new booking notification, accept booking.
4. **Rental Lifecycle**: Switch to Vendor Staff, issue equipment, then return equipment.
5. **Deposit Settlement**: Show refund calculations.
6. **Admin Flow**: Log in as Admin, show revenue and platform analytics.
